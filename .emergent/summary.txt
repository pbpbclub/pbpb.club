<analysis>**original_problem_statement:**
The user, a furniture production business owner, wants an internal application named Factory Hub to manage orders, clients, materials, a production calendar, and calculate planned vs. actual costs.

**PRODUCT REQUIREMENTS:**
- **Goal:** Track orders, manage a production calendar, and calculate planned vs. actual costs.
- **Data Models:**
    - **Order:** Contains details like ID, name, client, dates, status, costs, stages, files, and events.
    - **Stages:** Orders go through sequential stages (Project, Estimate, Production), with production having sub-stages (Welding, Painting, etc.).
    - **Clients:** A dedicated section to manage client information.
    - **Materials:** A database of materials with stock levels and sourcing information.
- **Cost Calculation:**
    - Costs are tracked per stage (materials + labor).
    - Sale price = Material cost + 60% markup.
- **Production Visualization:**
    - A production calendar with various views.
    - A Kanban-style board (Производство) to track the progress of all orders through production stages.
- **Interface:**
    - Must be minimalist, utilitarian, and fast, adhering to a strict color palette.
    - Main screens: Dashboard, Order List, Order Detail, Calendar, Materials, Clients, Production Board.
    - Key functionality: Add, edit, delete, filter data across all sections.
    - File management within each order.
    - Chronological event logging for each order.
- **Editing:** The user wants a seamless editing experience. When an Edit button is clicked on a detail page (like an Order), the entire page should become a form, allowing for inline editing of all fields across all tabs, rather than using a popup modal.

**User's preferred language**: Русский (Russian)
