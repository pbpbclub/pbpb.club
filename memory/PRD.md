# Factory Hub - PRD

## Оригинальная постановка задачи
Внутреннее приложение для управления заказами и расчёта себестоимости мебельного производства.
Интерфейс — максимально простой, утилитарный, без лишнего визуального шума.

## Основные требования
1. Вести производственный календарь
2. Фиксировать заказы и этапы их прохождения
3. Считать фактическую и плановую себестоимость изделий
4. Использовать исторические данные как основу логики расчётов

## Сущности (Data Model)
- **Заказ (Order)**: ID, Название, Клиент, Даты, Статус, Себестоимость, Комментарий
- **Этапы заказа (Stages)**: Создание проекта, Согласование сметы, Производство (Сварка, Покраска, Дерево, Мягкая мебель)
- **Клиенты (Clients)**: Название контрагента, ИНН, контактное лицо, телефон, email, примечания
- **Материалы (Materials)**: Название, тип, цена, единица измерения

## Себестоимость
- Логика: Сумма по этапам (Материалы, Работы)
- Продажная цена = сумма материалов + 60% наценка
- Безнал = Наличные / 0.87

## Технический стек
- Backend: FastAPI + MongoDB
- Frontend: React + TailwindCSS + Shadcn/UI
- Calendar: react-big-calendar
